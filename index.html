🔑 Connect this page to your repo (one-time, 1 minute)

GitHub Pages is a static site, so it can't run the automation by itself — it triggers the workflow in your repo, which does the real work. To trigger it, the page needs a GitHub token. The token is saved only in your own browser (local storage) — it is never sent to this site's server, and it is never put in the repo.

  1. Open Create a fine-grained token
  2. Repository access: select Only select repositories → automation
  3. Permissions → Actions: Read and write. That is all it needs.
  4. Create it, copy it, and paste it below.

Without a token you can still see the latest runs below — but the Run button needs one. You can also always run it from the repo: Actions → Lead Outreach → Run workflow.
